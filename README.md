# Simple PHP Blog (Clean PHP + Smarty + Docker + SCSS)

Простой, но полностью функциональный веб-сайт-блог с категориями и публикациями, разработанный на чистом **PHP 8.2** с использованием объектно-ориентированного программирования (ООП), шаблонизатора **Smarty 4** и реляционной базы данных **MySQL 8.0**.

Проект полностью разворачивается в изолированном **Docker**-окружении, а стили написаны на **SCSS** и компилируются в CSS «на лету» средствами самого PHP.

## 🚀 Стек технологий
* **Backend:** PHP 8.2 (ООП, кастомный Regex-роутер, паттерн Front Controller)
* **Database:** MySQL 8.0 (связи Один-ко-Многим и Многие-ко-Многим)
* **Template Engine:** Smarty 4.x
* **Styles:** SCSS (Компиляция через `scssphp/scssphp` без Node.js)
* **Environment:** Docker, Docker Compose, Nginx, phpMyAdmin
* **Testing Data:** Faker PHP

## 🛠️ Функциональные возможности
1. **Кастомный Роутинг:** Разбор красивых URL-адресов при помощи регулярных выражений (`/`, `/category/{id}`, `/article/{id}`).
2. **Компиляция SCSS "на лету":** PHP проверяет время изменения файла `scss/style.scss` при каждом запросе. Если он обновился — стили перекомпилируются автоматически.
3. **Flexbox Верстка:** Адаптивное расположение карточек, эффекты мягкого подъема блоков при наведении (`transition`, `transform`), темная контрастная шапка.
4. **Интерфейс базы данных:** Интегрирован сервис phpMyAdmin для визуального дебага таблиц.
5. **Генерация контента:** Наполнение базы данных реалистичным русским текстом с помощью библиотеки Faker PHP.

## 📥 Пошаговое развертывание

### 1. Клонирование и запуск контейнеров
Убедитесь, что у вас установлены Docker и Docker Compose. Выполните команду в корне вашего проекта:
```bash
docker-compose up -d --build
```
Это действие скачает необходимые образы и поднимет в фоне 4 сервиса: `blog_app`, `blog_nginx`, `blog_mysql` и `blog_phpmyadmin`.

### 2. Установка PHP зависимостей
Установите Smarty, Faker и компилятор SCSS внутри контейнера:
```bash
docker-compose exec app composer install
```

### 3. Выдача прав на папки
Для корректной записи кэша шаблонов Smarty и компиляции CSS выдайте права на запись:
```bash
docker-compose exec app mkdir -p storage/templates_c
docker-compose exec app chmod -R 777 storage public
```

### 4. Запуск миграций (создание таблиц)
Создайте структуру таблиц `categories`, `articles` и связующую таблицу `article_category`:
```bash
docker-compose exec app php migrations/001_create_tables.php
```

### 5. Запуск сидера (наполнение данными)
Автоматически скачается фоновое изображение для постов, создадутся 5 категорий и 30 статей с текстами на русском языке:
```bash
docker-compose exec app php seeds/run.php
```

## 📌 Проверка страниц проекта

* **Главная страница (`/`):** Выводит секции всех категорий, в которых есть посты. В каждой секции отображаются максимум 3 последних статьи и кнопка перехода.
* **Страница категории (`/category/{id}`):** Показывает описание категории, пагинацию (по 5 постов на страницу) и блок интерактивной сортировки по дате публикации или по количеству просмотров.
* **Страница статьи (`/article/{id}`):** При каждом открытии увеличивает счетчик просмотров на `+1`, выводит полный текст и блок из 3-х похожих статей из той же категории.

## 💡 Решение частых проблем
* **Не отображаются новые стили / съехала верстка:** Нажмите комбинацию клавиш `Ctrl + F5` (или `Cmd + Shift + R` на Mac), чтобы сбросить жесткий кэш стилей в браузере.
* **Ошибка Smarty Compiler:** Очистите кэш скомпилированных шаблонов внутри контейнера командой `docker-compose exec app rm -rf storage/templates_c/*`.
